# Product Admin
A product admin dashboard built with React, TypeScript, and Tailwind CSS.

I'm building this project to create a simple interface for managing products and handling common admin tasks. It also gives me an opportunity to work more with TypeScript, form validation, data tables, and state management in React.

## Tech Stack
- React 19
- TypeScript
- Tailwind CSS
- Vite
- React Router
- TanStack Query
- TanStack Table
- Zustand
- React Hook Form
- Zod
- Lucide React

## Getting Started

To run the project locally:

```bash
git clone https://github.com/theadullamite/product-admin.git
```

Move into the project directory:

```bash
cd product-admin
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Available Scripts
- `npm run dev` – Start the development server.
- `npm run build` – Build the project for production.
- `npm run lint` – Check the code for linting issues.
- `npm run preview` – Preview the production build.
